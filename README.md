# 주식 투자 바이블 (1단계)

주식 용어, 차트 모양, 기업 분석, 위험 관리를 연결해서 공부하는 무료 학습 웹앱입니다.
반응형 웹이면서 휴대폰 홈 화면에 설치할 수 있는 PWA입니다. 빌드 도구 없이 HTML·CSS·JavaScript 파일만으로 동작합니다.

## 1. 실행해 보기

### 가장 쉬운 방법: 미리보기 파일
`dist/preview.html`을 더블클릭하면 브라우저에서 바로 열립니다. (이 방식은 PWA 설치·오프라인 기능만 빠집니다)

### PWA까지 확인하기: 내 컴퓨터에서 웹 서버로 열기
파이썬이 설치되어 있다면 이 폴더에서 아래 한 줄을 실행하고, 브라우저에서 `http://localhost:8000` 을 엽니다.

```
python3 -m http.server 8000
```

(윈도우는 `python -m http.server 8000`)

### 무료로 인터넷에 공개하기 (GitHub Pages)
1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 모두 올립니다.
2. 저장소 Settings → Pages → Branch를 `main`, 폴더를 `/ (root)`로 지정합니다.
3. 몇 분 뒤 `https://내아이디.github.io/저장소이름/` 으로 접속됩니다. https 주소라서 휴대폰에서 "홈 화면에 추가"로 설치할 수 있습니다.

Cloudflare Pages도 같은 방식(빌드 명령 없음, 출력 폴더 `/`)으로 무료 배포됩니다.

## 2. 폴더 구조

| 위치 | 내용 | 비개발자가 수정할 일 |
|---|---|---|
| `js/content/terms.js` | 용어 50개 | 자주 (설명 고치기, 검토 상태 바꾸기) |
| `js/content/patterns.js` | 차트 패턴 10개 | 가끔 |
| `js/content/practice.js` | 연습 문제 8개 | 가끔 |
| `js/content/lessons.js` | 기업 분석·위험 관리 강의 | 가끔 |
| `js/content/meta.js` | 출처 목록, 수정 이력 | 콘텐츠를 고칠 때마다 이력 추가 |
| `js/providers/registry.js` | 데이터 공급자 연결 상태 | 2단계 연결 때 |
| `css/app.css` | 색·글꼴·배치 | 디자인 변경 때 |
| `js/core/` | 차트, 가상 데이터 생성, 통계 계산, 저장 | 개발자 영역 |
| `js/views/` | 화면별 코드 | 개발자 영역 |
| `sw.js` | 오프라인 저장 (PWA) | 배포할 때 `VERSION` 숫자 올리기 |
| `tools/` | 검사·미리보기 생성 스크립트 | 수정 후 실행 |
| `docs/` | 데이터 계획, 콘텐츠 작성 가이드, 앱스토어 확장 | 읽기 |

## 3. 콘텐츠를 고치는 순서

1. `js/content/terms.js` 등에서 글을 고칩니다. 글은 작은따옴표 `'...'` 안에 있습니다. 글 안에 작은따옴표를 쓰려면 `\'`로 씁니다.
2. 사람이 출처와 대조해 검토를 마쳤다면 그 항목의 `status: 'ai-draft'` 를 `status: 'reviewed'` 로, `reviewedAt`을 검토 날짜로 바꿉니다.
3. `js/content/meta.js`의 `CHANGELOG`에 한 줄 추가합니다.
4. 검사를 실행합니다: `node tools/validate-content.mjs` → "검사 통과"가 나오면 됩니다.
5. 미리보기 파일을 다시 만듭니다: `node tools/build-preview.mjs`
6. 배포한다면 `sw.js`의 `VERSION`을 올립니다(예: `sb-v0.1.1`). 올리지 않으면 이미 설치한 사람의 기기에 옛 버전이 남습니다.

자세한 작성 규칙은 `docs/CONTENT_GUIDE.md`에 있습니다.

## 4. AI로 수정을 맡길 때 쓰는 요청 예시

- "terms.js의 `per` 항목 쉬운 설명을 초급자용으로 더 짧게 고쳐줘. 다른 필드는 건드리지 마."
- "patterns.js에 '깃발형' 패턴을 기존 항목과 같은 필드 구조로 추가해줘. stats.status는 unverified로 두고, 수정 후 validate-content.mjs가 통과하는지 확인해줘."
- "practice.js에 문제를 하나 추가해줘. intended 값과 실제 생성 결과가 모든 시장·봉 주기에서 맞는지 검사로 확인해줘."

## 5. 구현된 기능 (1단계)

- 홈: 학습 수준·시장·투자 기간·봉 주기 선택, 이어서 공부하기, 설정 맞춤 추천, 진도
- 용어 사전 50개: 분류·수준·시장·기간 필터, 한국·미국 차이, 수준별 깊이, 퀴즈, 출처·검토 상태
- 차트 도감 10개: 성공·실패 사례 차트(설명용 가상 데이터), 형성 중/확인됨, 무효화 조건, 학습용 시나리오, 통계 미검증 표시
- 차트 연습실 8문제(무작위 차트 포함): 미래 가림 → 근거·반대 근거·추가 정보·판단을 바꿀 조건 기록 → 공개 → 과정과 결과를 따로 평가, 보류 허용
- 퀴즈 60문제: 현재 설정·오답만·전체 범위
- 기업 분석 기초: 강의 4개, PER·PBR·ROE 연결 계산기
- 위험 관리: 강의 5개, 손익비·투자 비중·비용·분산·낙폭/연속 손실·환율 계산기
- 검증·통계: 지표 정의, 검증 원칙 처리 현황, 재현 가능한 계산 엔진 시연(무작위 가상 데이터)
- 종목 탐구: 데이터 연결 상태 표시 (실제 데이터 미연결)
- 내 학습: 북마크, 오답 노트, 분야별 진도, 백업 내보내기·가져오기, 초기화
- 검색, 다크 모드, 모바일 하단 탭, 차트 확대·축소·끌기·두 손가락 확대, PWA 설치·오프라인

## 6. 아직 하지 않은 것

- 실제 주가, 종목 검색, 공시·재무 연결 (2단계) → `docs/DATA_PLAN.md`
- 실제 데이터로 계산한 패턴 통계 (3단계). 지금은 모든 패턴이 "통계 미검증"
- 여러 기기 동기화 (지금은 기기 내 저장 + 백업 파일)
- 분봉 데이터, 차트 이미지 업로드 분석
- 콘텐츠 사람 검토 (전부 "AI 초안 · 검토 전")
