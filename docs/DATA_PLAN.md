# 데이터 확보 계획과 비용

확인일: 2026-10-15. 이용 조건과 가격은 바뀔 수 있으니 연결 직전에 공식 페이지에서 다시 확인합니다.

## 원칙

1. 학습용 차트는 직접 만든 합성 데이터를 우선 사용하고 "설명용 가상 데이터"로 표시한다.
2. 무료 API로 **가져올 수 있는지**와 무료 공개 서비스에 **보여줄 수 있는지**는 따로 확인한다. 공개 표시, 저장, 통계 가공, 재배포 권한을 각각 확인한다.
3. 데이터 공급 코드는 `js/providers/registry.js` 한 곳에 모아 교체할 수 있게 한다.
4. API 키는 브라우저 코드에 넣지 않는다. 키가 필요한 공급자는 서버 중계(프록시)를 거친다.
5. 실제 차트는 종목·시장·통화·봉 주기·기간·출처·기준 시점이 없으면 그려지지 않도록 코드로 막았다(`js/core/chart.js`).

## 2단계 연결 순서 (제안)

1. **서버 중계 만들기**: Cloudflare Workers 같은 무료 등급 서버리스 함수에 API 키를 비밀 값으로 넣고, 브라우저는 이 중계 주소만 부른다. 중계에서 요청 속도 제한(EDGAR 초당 10회 이하)과 결과 저장(캐시)을 처리한다.
2. **SEC EDGAR 연결**: 키가 필요 없어 가장 먼저 연결하기 쉽다. 단, User-Agent 헤더는 브라우저에서 바꿀 수 없으므로 중계 서버에서 붙인다.
3. **OpenDART 연결**: 중계 서버에만 키를 보관. 재무 숫자에는 공시 접수일(`rcept_dt`)을 함께 저장해 "언제부터 알 수 있었는지"를 기록한다(미래 정보 편향 방지).
4. **주가 데이터**: 공개 표시·재배포 권한을 서면(약관)으로 확인한 공급자만 연결. 권한이 불명확하면 연결하지 않고 화면에 "미연결"을 유지한다.
5. `registry.js`에서 해당 공급자의 `status`를 `connected`로 바꾸고 `fetch` 함수를 추가한다.

## 3단계 통계에 필요한 데이터

- 상장폐지 종목을 포함한 과거 일봉 (생존편향 방지)
- 당시 기준 지수 구성 종목 목록
- 분할·배당 조정 기준이 명시된 가격
- 같은 시장 비교 기준(지수 또는 전체 종목 무조건 진입)

무료 데이터로는 상장폐지 종목 확보가 어려운 경우가 많습니다. 확보하지 못하면 해당 통계는 "계산 불가"로 둡니다.

## 예상 비용

| 시점 | 항목 | 비용 | 필요한 이유 |
|---|---|---|---|
| 1단계(지금) | 정적 호스팅 (GitHub Pages, Cloudflare Pages) | 0원 | 정적 파일만 배포 |
| 1단계 | 도메인 (선택) | 연 1~3만 원 정도 | 없어도 무료 주소로 운영 가능 |
| 2단계 | 서버 중계 | 무료 등급에서 시작 가능 | API 키 보호, 요청 제한. 무료 한도는 공급사에서 확인 |
| 2단계 | 주가 데이터 공개 표시 권한 | 0원 ~ 월 수만~수십만 원 | 무료 API는 공개 재배포를 허용하지 않는 경우가 많음 |
| 3단계 | 상장폐지 포함 과거 데이터 | 유료 가능성 높음 | 생존편향 없는 통계 |
| 앱스토어 | Google Play 개발자 등록 | 25달러, 1회 | Android 출시 |
| 앱스토어 | Apple Developer Program | 연 99달러 (공식 확인 필요) | iOS 출시, 매년 갱신 |
| 별도 확장 | 이용할 때마다 AI 호출 | 사용량 비례 | 1단계에는 없음 |

## 이용 시 AI 호출을 도입한다면 (별도 확장)

- 같은 질문의 해설은 저장해 재사용하고, 사용자·하루당 호출 한도를 둔다.
- 호출 실패 시 저장된 기본 해설을 보여주고 기능은 계속 동작하게 한다.
- AI가 수익·손실 확률을 만들지 못하게, 확률은 통계 엔진 결과만 전달해 설명하게 한다.
- 예상 비용 = 하루 호출 수 × 호출당 토큰 × 모델 단가. 도입 전에 한도로 상한을 고정한다.
